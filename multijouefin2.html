Règles du Monopoly

Guide de l'Écran de Démarrage

Cet écran vous permet de configurer entièrement votre partie de Monopoly. Chaque section est expliquée ci-dessous. Survolez les pour plus de détails sur les règles avancées.

1. Mode de Jeu

Basculez entre le plateau 2D traditionnel, rapide et clair, et une expérience 3D immersive.

Mode 2D : Vue de dessus classique, idéale pour une stratégie rapide.
Mode 3D : Un plateau et des pions entièrement modélisés pour une immersion totale. Ce mode peut être plus exigeant pour votre ordinateur.

2. Joueurs & Équipes

Jusqu'à 24 joueurs peuvent participer ! Configurez chaque joueur :
- Nom : Personnalisez le nom.
- Type : Humain ou IA (plusieurs difficultés).
- Pion & Couleur : Choisissez parmi des centaines d'icônes ou chargez vos propres modèles 3D.
- Mode Équipe : Activez pour des alliances stratégiques. Les membres d'une même équipe ne se paient pas de loyer.

3. Règles Avancées & Personnalisation

Transformez chaque partie avec des règles uniques. Survolez l'icône à côté de chaque règle dans le menu principal pour une explication détaillée.

Modes Spéciaux : Activez le mode Tour Eiffel pour des constructions grandioses ou le Marché Boursier pour une dimension économique supplémentaire.
Éditeur : Créez vos propres plateaux, modifiez les cartes Chance et Communauté pour un jeu 100% unique.

Règles Avancées

4. Actions Finales

Lancer la Partie : Démarre le jeu avec la configuration actuelle.

Reprendre la partie : Charge automatiquement votre dernière session de jeu.

Gérer les sauvegardes : Chargez ou supprimez des parties sauvegardées spécifiques. Vous pouvez avoir plusieurs sauvegardes nommées.

Gérer les Personnalisations : Chargez, sauvegardez ou supprimez vos propres créations de plateaux et de règles.
